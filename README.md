# Employee Attrition Predictor

A multi-algorithm machine learning project that predicts employee attrition using the IBM HR Analytics dataset, comparing five classification algorithms and using SHAP for model explainability. Built to demonstrate algorithm fluency, imbalanced classification handling, and business-oriented interpretation of model outputs.

## Problem Statement

Employee attrition is costly — replacing an employee can cost 50-200% of their annual salary in recruiting, onboarding, and lost productivity. This project builds a classification pipeline to identify employees at risk of leaving, using systematic comparison across five algorithms and translating model outputs into actionable HR insights via SHAP.

## Dataset

**IBM HR Analytics Employee Attrition Dataset** — 1,470 employees, 35 features, binary target (`Attrition`: Yes/No).
Download from [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) and place the CSV in the project root before running the notebooks.

- Target imbalance: ~16.1% attrition rate
- Zero-variance columns dropped: `EmployeeCount`, `StandardHours`, `Over18`
- ID column dropped: `EmployeeNumber`

## Methodology

**1. EDA** — Identified class imbalance, feature distributions (skew analysis), categorical vs. attrition cross-tabs, and multicollinearity among numeric features.

**2. Preprocessing** — Encoded categorical features (OneHot for nominal, ordinal mapping for `BusinessTravel`), stratified 80/20 train-test split, `StandardScaler` applied post-split to prevent data leakage, SMOTE applied to training data only to address class imbalance.

**3. Model Training** — Trained and compared five classifiers on identical data splits:

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|
| Logistic Regression | 0.769 | 0.36 | 0.60 | 0.45 | 0.790 |
| KNN | 0.633 | 0.23 | 0.55 | 0.33 | 0.613 |
| Naive Bayes | 0.497 | 0.20 | 0.70 | 0.31 | 0.644 |
| Random Forest | 0.833 | 0.46 | 0.23 | 0.31 | 0.80 |
| **XGBoost** | 0.864 | 0.67 | 0.30 | 0.41 | 0.795 |
| **XGBoost (threshold=0.3)** | 0.871 | 0.645 | 0.426 | **0.513** | 0.795 |

**Best model: XGBoost with a tuned classification threshold of 0.3** (vs. default 0.5), selected for the highest ROC-AUC among top performers and the best precision-recall balance (F1) after threshold adjustment — prioritizing recall given the higher business cost of missing at-risk employees versus false alarms.

**4. Explainability (SHAP)** — `TreeExplainer` applied to the final model. Top predictors: `OverTime`, `StockOptionLevel`, `MonthlyIncome`, `NumCompaniesWorked`, `JobSatisfaction`. Individual-level waterfall plots generated to explain specific predictions, alongside global summary and dependence plots.

## Key Findings

- Employees working overtime leave at ~3x the rate of those who don't — the single strongest predictor
- Having *any* stock options meaningfully reduces attrition risk; additional equity beyond that shows diminishing returns
- Low income combined with overtime work compounds risk beyond either factor alone
- The relationship between model choice and threshold choice matters as much as algorithm selection — XGBoost's default threshold under-predicted attrition, but tuning it recovered significant recall without retraining
